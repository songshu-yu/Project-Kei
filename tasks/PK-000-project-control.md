# PK-000 — 架构总控与集成

- 状态：进行中
- 优先级：持续
- 所属模块：`project_control`
- 负责路径：`TASKS.md`、`AGENTS.md`、`tasks/_TEMPLATE.md`、`docs/architecture/`、跨模块契约与项目门禁脚本

## 目标

维护模块边界、优先级、公共接口和集成节奏；具体功能实现转交对应独立任务。

## 职责

- 审批跨模块依赖和兼容接口变化。
- 把新需求分配到唯一任务，避免多个对话修改同一职责。
- 决定任务何时从“待集成”进入“已完成”。
- 不在总控对话中堆积单个功能的详细实现过程。

## 验收标准

- `TASKS.md` 与真实项目状态一致。
- 每项跨模块改动都有负责模块、接口契约和集成任务。
